# Docker Learning Journal

Learning Docker in public — as a Java Full Stack Developer (Spring Boot + React + MySQL).

This repo documents my self-learning process: what I searched, what I understood, what confused me, and any hands-on practice/code I built along the way. No copied tutorials — just my own notes as I go.

## Background

I'm a Java full stack developer (Spring Boot, React, MySQL) with ~6 months of experience. Learning Docker to properly package and run my applications, and to make my projects deployment-ready.

## Roadmap / Progress

- [ ] **Phase 1: Docker Basics** — containers vs VMs, images, core CLI commands
- [ ] **Phase 2: Dockerfile** — writing my own Dockerfiles, multi-stage builds
- [ ] **Phase 3: Docker Compose** — running Spring Boot + React + MySQL together
- [ ] **Phase 4: Volumes & Networking** — data persistence, container networking
- [ ] **Phase 5: Spring Boot Specific Gotchas** — config, health checks, JVM tuning in containers
- [ ] **Phase 6: Real Project** — dockerizing an actual project end to end

Check items off as I complete each phase.
